# Grünwelle Live

Ampel-Assistent als Web-App: Hybrid aus TrafficPilot (Ampelprognose, Tempo-Empfehlung) und Waze (Meldungen).

- Echtes GPS im Browser (Safari auf dem iPhone), Home-Bildschirm-App
- Ampelstandorte, Blitzer und Baustellen aus OpenStreetMap und der Autobahn-API (täglich per GitHub Action)
- Schaltzeiten werden aus den Fahrten aller Nutzer gelernt und über Supabase geteilt
- Navigation mit Spurassistent, Sprach- oder Tonansagen, Suche mit Treffern in der Nähe zuerst
- Meldungen (Polizei, Unfall, Stau, Gefahr, Baustelle) für alle, eigene löschbar
- Straßenbahn-Abfahrten Leipzig (Fahrplan), DWD-Wetterwarnungen, gespeicherte Orte, Simulation zum Testen

Quellen: © OpenStreetMap-Mitwirkende, OpenFreeMap, Photon, OSRM/FOSSGIS, DELFI/gtfs.de (CC BY 4.0), Deutscher Wetterdienst über Bright Sky.
Projektstand für die Weiterentwicklung: [PROJEKT.md](PROJEKT.md)

**Sicherheit:** Handy in die Halterung, vor der Fahrt einstellen, während der Fahrt nicht tippen. Die Empfehlung ist nur eine Schätzung, die echte Ampel hat Vorrang.
