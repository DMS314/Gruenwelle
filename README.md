# Grünwelle Live

Ampel-Assistent als Web-App: Hybrid aus TrafficPilot (Ampelprognose, Tempo-Empfehlung) und Waze (Meldungen).

- Echtes GPS im Browser (Safari auf dem iPhone, https nötig)
- Ampelstandorte aus OpenStreetMap (Overpass API)
- Schaltzeiten werden aus den eigenen Fahrten gelernt (Halten, Losfahren, Durchfahrten bei Grün)
- Eigene Meldungen (Polizei, Unfall, Stau, Gefahr, Baustelle), nur lokal gespeichert
- Export/Import der gelernten Daten

Alle Daten bleiben auf dem Gerät. Karte und Ampeldaten: © OpenStreetMap-Mitwirkende.

**Sicherheit:** Handy in die Halterung, vor der Fahrt einstellen, während der Fahrt nicht tippen. Die Empfehlung ist nur eine Schätzung, die echte Ampel hat Vorrang.
